Typography components give you semantic text styles that follow shadcn/ui conventions: proper font sizes, weights, tracking, and colors that adapt to dark mode. Every component accepts a content string as a positional argument and supports `{{ field }}` interpolation.

## Components

### Headings

### Body Text

`P` renders a standard paragraph. `Lead` is larger and muted for introductory text. `Large` emphasizes key information. `Text` renders an unstyled span for maximum flexibility.

### Markdown

For rich text with links, lists, and other formatting, use `Markdown` with standard markdown syntax:

```python
from prefab_ui.components import Markdown

Markdown("**Bold** and *italic* text with [links](https://example.com).")
```

## Formatting

### Text Modifiers

All text components accept formatting kwargs: `bold`, `italic`, `underline`, `strikethrough`, `uppercase`, and `lowercase`. These compile to Tailwind classes and work alongside `css_class`.

### Inline Formatting with Span

To style individual words within a sentence, pass mixed strings and `Span` components to `Text`. Strings are automatically wrapped as plain spans; you only need `Span` for the parts that need styling.

## API Reference

<Card icon="code" title="Common Parameters">

All text components (`H1`-`H4`, `P`, `Lead`, `Large`, `Small`, `Muted`, `Text`, `Span`, `BlockQuote`, `InlineCode`) share this interface:

<ParamField body="content" type="str" required>
  Text content. Accepts `{{ field }}` interpolation. Can be passed as a positional argument.
</ParamField>

<ParamField body="bold" type="bool | None" default="None">
  Bold weight.
</ParamField>

<ParamField body="italic" type="bool | None" default="None">
  Italic style.
</ParamField>

<ParamField body="underline" type="bool | None" default="None">
  Underline decoration.
</ParamField>

<ParamField body="strikethrough" type="bool | None" default="None">
  Strikethrough decoration.
</ParamField>

<ParamField body="uppercase" type="bool | None" default="None">
  Transform text to uppercase.
</ParamField>

<ParamField body="lowercase" type="bool | None" default="None">
  Transform text to lowercase.
</ParamField>

<ParamField body="align" type='"left" | "center" | "right" | "justify" | None' default="None">
  Horizontal text alignment.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes.
</ParamField>
</Card>

<Card icon="code" title="Text">

Accepts mixed positional args for inline formatting:

```python
Text("plain string")
Text("Click ", Span("here", bold=True), " to continue")
```

</Card>

<Card icon="code" title="Heading">
<ParamField body="level" type="int" default="1">
  Heading level: `1` (h1), `2` (h2), `3` (h3), or `4` (h4).
</ParamField>
</Card>

<Card icon="code" title="Span">
<ParamField body="style" type="dict[str, str] | None" default="None">
  Inline CSS styles as a dict of property/value pairs.
</ParamField>
</Card>

## Protocol Reference

```json Text
{
  "type": "Text",
  "content?": "string",
  "children?": [{"type": "Span", "content": "..."}],
  "bold?": "boolean",
  "italic?": "boolean",
  "align?": "left | center | right | justify",
  "cssClass?": "string"
}
```

```json Heading
{
  "type": "Heading",
  "content": "string (required)",
  "level?": "1 | 2 | 3 | 4",
  "bold?": "boolean",
  "italic?": "boolean",
  "cssClass?": "string"
}
```

For the complete protocol schema, see [Text](/protocol/text), [Heading](/protocol/heading), [Span](/protocol/span), [Markdown](/protocol/markdown).
