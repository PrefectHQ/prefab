The Markdown component renders full markdown content — headings, bold, italic, lists, links, code blocks, tables, and blockquotes. Use it for rich text blocks where the content is naturally markdown-shaped.

Version **2.5.0** brings several improvements:

## New Features

- **Dark mode** with automatic system detection
- Keyboard shortcuts for *all* actions
- Inline `code` formatting support

## Migration Guide

> Update your config file before upgrading.

| Setting | Old | New |
|---------|-----|-----|
| theme | `light` | `auto` |
| timeout | `30s` | `60s` |
""")
