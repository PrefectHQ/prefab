DataTable takes flat `columns` and `rows` and renders a full-featured table with optional sorting, search filtering, and pagination. Use it when you have structured data and want interactive table features without building the markup yourself.

## Cell Formatting

The `format` field on `DataTableColumn` formats numeric and date values without requiring a component cell. Use `'type'` or `'type:arg'` syntax to control the output.

Supported format strings:

| Format | Example output | Notes |
|--------|---------------|-------|
| `number` | `1,234,567` | Locale thousands separator |
| `number:2` | `1,234.50` | Fixed decimal places |
| `currency` | `$1,234.50` | USD by default |
| `currency:EUR` | `€1,234.50` | Any ISO 4217 code |
| `percent` | `14%` | Value should be `0.14`, not `14` |
| `percent:1` | `14.2%` | Fixed decimal places |
| `date` | `Mar 15, 2023` | Medium style by default |
| `date:short` | `3/15/23` | short / medium / long / full |
| `date:long` | `March 15, 2023` | |

## Column Width and Alignment

Control column sizing with `width`, `min_width`, and `max_width`, and align cell content with `align`. The `align` convenience field resolves to `cell_class` Python-side — it never appears in the protocol.

```python
DataTable(
    columns=[
        DataTableColumn(key="id", header="ID", width="80px", align="center"),
        DataTableColumn(key="name", header="Name", min_width="150px"),
        DataTableColumn(
            key="amount",
            header="Amount",
            align="right",
            cell_class="font-mono",
            header_class="text-right",
        ),
    ],
    rows=[
        {"id": "001", "name": "Alice Johnson", "amount": "$1,200.00"},
        {"id": "002", "name": "Bob Smith", "amount": "$850.50"},
    ],
)
```

Use `header_class` and `cell_class` for arbitrary Tailwind styling on individual columns — truncation, font weights, color coding, and so on.

## API Reference

<Card icon="code" title="DataTable Parameters">
<ParamField body="columns" type="list[DataTableColumn]" required>
  Column definitions. Each column specifies a `key`, `header`, and optional `sortable` flag.
</ParamField>

<ParamField body="rows" type="list[dict] | str" default="[]">
  Row data as a list of dicts, or a `{{ field }}` interpolation reference.
</ParamField>

<ParamField body="filter" type="bool" default="False">
  Show a search/filter input above the table.
</ParamField>

<ParamField body="paginated" type="bool" default="False">
  Show pagination controls below the table.
</ParamField>

<ParamField body="page_size" type="int" default="10">
  Number of rows per page when `paginated=True`.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes.
</ParamField>
</Card>

<Card icon="code" title="DataTableColumn Parameters">
<ParamField body="key" type="str" required>
  Data key — matches keys in the row dicts.
</ParamField>

<ParamField body="header" type="str" required>
  Column header display text.
</ParamField>

<ParamField body="sortable" type="bool" default="False">
  Enable click-to-sort on this column.
</ParamField>

<ParamField body="format" type="str | None" default="None">
  Format string for cell values. Accepts `number`, `number:N`, `currency`, `currency:CODE`,
  `percent`, `percent:N`, `date`, `date:short|medium|long|full`. Ignored when the cell value is a component.
</ParamField>

<ParamField body="width" type="str | None" default="None">
  Column width CSS value (e.g. `"200px"`, `"30%"`).
</ParamField>

<ParamField body="min_width" type="str | None" default="None">
  Minimum column width CSS value.
</ParamField>

<ParamField body="max_width" type="str | None" default="None">
  Maximum column width CSS value.
</ParamField>

<ParamField body="align" type='"left" | "center" | "right" | None' default="None">
  Cell text alignment. Resolves Python-side to `cell_class` — does not appear in the protocol.
</ParamField>

<ParamField body="header_class" type="str | None" default="None">
  Tailwind classes applied to the header cell for this column.
</ParamField>

<ParamField body="cell_class" type="str | None" default="None">
  Tailwind classes applied to every data cell in this column.
</ParamField>
</Card>
