Carousel is a single component that handles three use cases through configuration: interactive slideshows where users navigate with arrows and dots, ambient reels that auto-advance on a timer, and continuous marquees that scroll smoothly without stopping. Each child becomes one slide.

## Carousel

Swipe, drag, or use the arrow buttons to navigate. Each slide fills the viewport by default:

## API Reference

<ParamField body="visible" type="float | None" default="1">
  Slides visible at once. Use a float for peek: `1.3` shows one slide plus 15% of the adjacent slides on each side. `None` = natural slide sizing.
</ParamField>

<ParamField body="gap" type="int" default="0">
  Pixels between slides.
</ParamField>

<ParamField body="height" type="int | None" default="None">
  Fixed height in pixels. Vertical carousels auto-detect from the first slide's content.
</ParamField>

<ParamField body="direction" type="str" default="left">
  Scroll direction: `"left"`, `"right"`, `"up"`, or `"down"`.
</ParamField>

<ParamField body="loop" type="bool" default="True">
  Seamless infinite looping.
</ParamField>

<ParamField body="auto_advance" type="int" default="0">
  Milliseconds between auto-advances. `0` = manual only.
</ParamField>

<ParamField body="continuous" type="bool" default="False">
  Smooth continuous scroll (marquee mode). Children are auto-duplicated for seamless looping.
</ParamField>

<ParamField body="speed" type="int" default="2">
  Scroll speed for continuous mode (1-10).
</ParamField>

<ParamField body="effect" type="str" default="slide">
  Transition effect: `"slide"` or `"fade"`.
</ParamField>

<ParamField body="dim_inactive" type="bool" default="False">
  Reduce opacity on non-active slides.
</ParamField>

<ParamField body="show_controls" type="bool" default="True">
  Show previous/next navigation arrows.
</ParamField>

<ParamField body="controls_position" type="str" default="overlay">
  Arrow position: `"overlay"` (on top of slides) or `"outside"` (flanking the viewport).
</ParamField>

<ParamField body="show_dots" type="bool" default="False">
  Show pagination dots.
</ParamField>

<ParamField body="pause_on_hover" type="bool" default="True">
  Pause auto-advance or continuous scroll on hover.
</ParamField>

<ParamField body="align" type="str" default="start">
  Slide alignment: `"start"`, `"center"`, or `"end"`.
</ParamField>

<ParamField body="slides_to_scroll" type="int" default="1">
  Slides to advance per navigation step.
</ParamField>

<ParamField body="drag" type="bool" default="True">
  Allow drag/swipe to navigate.
</ParamField>

<ParamField body="css_class" type="str">
  Additional CSS classes.
</ParamField>
