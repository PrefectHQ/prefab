Loaders communicate that something is happening — a request in flight, content loading, or a background process running. Three visual variants cover the most common patterns.

## Sizes

Badges accept children, so you can embed a loader directly inside and control the order.

<ComponentPreview json={{"view":{"cssClass":"gap-4 items-center","type":"Row","children":[{"type":"Badge","variant":"default","children":[{"type":"Loader","variant":"spin","size":"sm"},{"content":"Syncing","type":"Text"}]},{"type":"Badge","variant":"secondary","children":[{"type":"Loader","variant":"dots","size":"sm"},{"content":"Processing","type":"Text"}]},{"type":"Badge","variant":"outline","children":[{"type":"Loader","variant":"pulse","size":"sm"},{"content":"Connected","type":"Text"}]}]}}} playground="H4sIAAAAAAAC_32Nva7CMAxG9z6FlalIuUxMSF1gZbgCdhQSUyK1dhW7_D09KSCEhKgny9_ncw6JW-gSHtx-18ep57ZjQlKBmLeksOazhYULNVpYsQuYLGzxokVxjnoc4rJ2XTWz4EV2vnEilYmKrfz5zMFkJvMC8jzqD1D5ugzzRJYSb1gZac3knQyS0myu5CPVr_sH4-RSdKT5CT1TcOlqvrHvUmAVY-Gn5j-xR5FxE_faRMIxT9c3gmOiJROhVww5uQMsJrFPfAEAAA">
<CodeGroup>
```python Python icon="python"
from prefab_ui.components import Row, Badge, Loader, Text

with Row(gap=4, css_class="items-center"):
    with Badge():
        Loader(size="sm")
        Text("Syncing")
    with Badge(variant="secondary"):
        Loader(variant="dots", size="sm")
        Text("Processing")
    with Badge(variant="outline"):
        Loader(variant="pulse", size="sm")
        Text("Connected")
```
```json Protocol icon="brackets-curly"
{
  "view": {
    "cssClass": "gap-4 items-center",
    "type": "Row",
    "children": [
      {
        "type": "Badge",
        "variant": "default",
        "children": [
          {"type": "Loader", "variant": "spin", "size": "sm"},
          {"content": "Syncing", "type": "Text"}
        ]
      },
      {
        "type": "Badge",
        "variant": "secondary",
        "children": [
          {"type": "Loader", "variant": "dots", "size": "sm"},
          {"content": "Processing", "type": "Text"}
        ]
      },
      {
        "type": "Badge",
        "variant": "outline",
        "children": [
          {"type": "Loader", "variant": "pulse", "size": "sm"},
          {"content": "Connected", "type": "Text"}
        ]
      }
    ]
  }
}
```
</CodeGroup>

## API Reference

<Card icon="code" title="Loader Parameters">
<ParamField body="variant" type="str" default="spin">
  Animation style: `"spin"`, `"dots"`, `"pulse"`, `"bars"`, `"ios"`.
</ParamField>

<ParamField body="size" type="str" default="default">
  Indicator size: `"sm"`, `"default"`, `"lg"`.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes.
</ParamField>
</Card>

## Protocol Reference

```json Loader
{
  "type": "Loader",
  "variant?": "spin | dots | pulse | bars | ios",
  "size?": "sm | default | lg",
  "cssClass?": "string"
}
```

For the complete protocol schema, see [Loader](/protocol/loader).
