## With Actions

The `on_change` parameter runs actions when the checkbox is toggled. `$event` is `true` when checked, `false` when unchecked:

<ComponentPreview json={{"view":{"cssClass":"gap-4 w-fit mx-auto","type":"Column","children":[{"name":"accepted","type":"Checkbox","label":"Accept terms","checked":false,"disabled":false,"required":false,"onChange":{"action":"setState","key":"message","value":"{{ $event ? 'Thank you!' : 'Please accept to continue' }}"}},{"cssClass":"text-muted-foreground","content":"{{ message | default:'Check the box' }}","type":"Text"}]}}} playground="H4sIAL1FuGkC_11QuW7DMAzd9RWs0MEGbE-dCngo8gNBkz2gFfpALNGQqMb9-yqGnaMcBB7iO9h6tjB5arE5xaEybCd25CTAkDIvsOvJXBqeC9jxGK0r4EizqPZ1D40M7O5LB5KDoND_b37efnzPStFPIoI65Zl-XwqdK0shYEdre61SX10H6VcNWYdT_VGACeFkRgyh1teyHQTsXGIU1vmnghSb9mypbjFiQ2Otv4yhSUDI26CL-9ShpVrjMqTz04DdyfToOqo3Zw_IW9x1Fi_txVMlPblMH9P-BX45vukC9H4kDAS46mAw7GRwMTl9QKxpvry3qz9IV77qnC4bR8n0YhUSFSS_zyBPN5IEUdqYrJUte-o8R7e5zNUfiiBZTgoCAAA">
<CodeGroup>
```python Python icon="python"
from prefab_ui.components import Checkbox, Column, Text
from prefab_ui.actions import SetState
from prefab_ui.rx import Rx

event = Rx("$event")
message = Rx("message")

with Column(gap=4, css_class="w-fit mx-auto"):
    Checkbox(
        label="Accept terms",
        name="accepted",
        on_change=SetState(
            "message",
            event.then("Thank you!", "Please accept to continue"),
        ),
    )
    Text(
        message.default("Check the box"),
        css_class="text-muted-foreground",
    )
```
```json Protocol icon="brackets-curly"

  "view": {
    "cssClass": "gap-4 w-fit mx-auto",
    "type": "Column",

        "label": "Accept terms",

        "required": false,

          "action": "setState",
          "key": "message",

      {
        "cssClass": "text-muted-foreground",
        "content": "{{ message | default:'Check the box' }}",
        "type": "Text"

  }
}
```

## Reading the Value

Use `.rx` to get a reactive reference to the checkbox's boolean state. The `.then()` pipe converts `true`/`false` into display-friendly strings:

'Engaged' : 'Disengaged' }}","disabled":false,"readOnly":true,"required":false}]}}} playground="H4sIAL1FuGkC_z2OvW7DMAyEdz8FoUkGBE-dAmhqOhToFHQPKJm2icqSQEv5efvKblBORxzvO06SVshCE7pr5cGnNadIsWzATUmB94X8j0sPA58x12LgCx0FA5d077o7l2VXesZs3wxg4Dla5RuARPWnDtp4B_Yfo8Met-ojogvUmBNHLk2sWZJDx4HLE87CN1IG_J6i0X5Lpf6AHe1aHQewFSx1O6k_6_hP3zBUst4N8hjKQlG3qhlnGhtOnXmj19YbEMLxmmJ4vvi_RwYo5AwBAAA">
<CodeGroup>
```python Python icon="python"
from prefab_ui.components import Checkbox, Input, Label, Row

with Row(gap=4, align="center"):
    cb = Checkbox(label="Enable Infinite Improbability Drive", checked=True)
    Label("Drive status:")
    Input(value=cb.rx.then("Engaged", "Disengaged"), read_only=True)
```

## API Reference

<Card icon="code" title="Checkbox Parameters">

<ParamField body="label" type="str | None" default="None">
  Label text displayed next to the checkbox.
</ParamField>

<ParamField body="checked" type="bool" default="False">
  Whether the checkbox is initially checked.
</ParamField>

<ParamField body="name" type="str | None" default="None">
  State key for the checkbox's checked state. Auto-generated if not provided. Use `.rx` to reference the checkbox's boolean value in other components.
</ParamField>

<ParamField body="value" type="str | None" default="None">
  Form value when checked.
</ParamField>

<ParamField body="disabled" type="bool" default="False">
  Whether the checkbox is non-interactive.
</ParamField>

<ParamField body="required" type="bool" default="False">
  Whether the checkbox is required for form submission.
</ParamField>

<ParamField body="on_change" type="Action | list[Action] | None" default="None">
  Action(s) to execute when toggled. `$event` is `true` when checked, `false` when unchecked.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes appended to the component's built-in styles.
</ParamField>
</Card>
