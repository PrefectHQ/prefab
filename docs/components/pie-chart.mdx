PieChart shows how parts relate to a whole. Specify which data field holds the numeric values (`data_key`) and which holds the labels (`name_key`). You can combine categories into an `Other` slice and set `inner_radius` to turn the chart into a donut.

## Grouping Slices

Combine smaller categories into one `Other` slice to keep a busy chart readable. Aggregation preserves the total: every row contributes either to its own slice or to `Other`. Choose an automatic cutoff or a list of categories to show individually.

### Automatic Cutoff

`aggregate_below` compares each value with a fraction of the original total. With `aggregate_below=0.2`, slices below 20% join `Other`; slices exactly at 20% stay separate. Here the total is 100, so US and MX remain individual slices and IN becomes `Other` with a value of 10.

### Selected Slices

Use `aggregate_except` when your app lets users choose which categories deserve their own slices. Its list matches values of `name_key`; all remaining rows contribute to `Other`. Bind the list to state so changing the selection immediately recalculates the chart.

This example starts with US=100 and Other=30. Selecting **Show MX** pulls MX=20 into its own slice and reduces Other to 10. **Group MX** combines it again, keeping the total at 130 throughout.

```python Selected slices icon="python"
from prefab_ui import PrefabApp
from prefab_ui.actions import SetState
from prefab_ui.components import Button, Column, Row
from prefab_ui.components.charts import PieChart
from prefab_ui.rx import STATE

with PrefabApp(
    state={
        "sales": [
            {"country": "US", "revenue": 100},
            {"country": "MX", "revenue": 20},
            {"country": "IN", "revenue": 10},
        ],
        "selected_countries": ["US"],
    }
):
    with Column():
        with Row():
            Button(
                "Show MX",
                on_click=SetState("selected_countries", ["US", "MX"]),
            )
            Button("Group MX", on_click=SetState("selected_countries", ["US"]))
        PieChart(
            data=STATE.sales,
            name_key="country",
            data_key="revenue",
            aggregate_except=STATE.selected_countries,
            show_label=True,
        )
```

Choose one aggregation option per chart. An empty `aggregate_except` list combines all rows, and `Other` is omitted when no rows are combined. Aggregation accepts finite, non-negative numeric values and distinct label and value fields. An existing category named `Other` joins the combined bucket when one is needed. With a zero total, automatic cutoff leaves the rows unchanged.

## API Reference

<Card icon="code" title="PieChart Parameters">
<ParamField body="data" type="list[dict] | str" required>
  Data as a list of dicts, or a `{{ field }}` interpolation reference.
</ParamField>

<ParamField body="data_key" type="str" required>
  The data field containing numeric values to plot as slice sizes.
</ParamField>

<ParamField body="name_key" type="str" required>
  The data field containing labels for each slice.
</ParamField>

<ParamField body="aggregate_below" type="float | None" default="None">
  Combine slices below this fraction of the original total into `Other`. Accepts 0 through 1; slices exactly at the cutoff stay separate. Mutually exclusive with `aggregate_except`.
</ParamField>

<ParamField body="aggregate_except" type="list[str] | Rx | None" default="None">
  Keep these `name_key` values as individual slices and combine the remaining rows into `Other`. Accepts a literal list or reactive state binding. Mutually exclusive with `aggregate_below`.
</ParamField>

<ParamField body="height" type="int" default="300">
  Chart height in pixels.
</ParamField>

<ParamField body="inner_radius" type="int" default="0">
  Inner radius in pixels. Set greater than 0 for a donut chart.
</ParamField>

<ParamField body="show_label" type="bool" default="False">
  Show a label on each slice.
</ParamField>

<ParamField body="padding_angle" type="int" default="0">
  Angle in degrees between slices.
</ParamField>

<ParamField body="show_legend" type="bool" default="True">
  Show a legend below the chart.
</ParamField>

<ParamField body="show_tooltip" type="bool" default="True">
  Show tooltips on hover.
</ParamField>

<ParamField body="value_format" type="str" default='"auto"'>
  Format tooltip values with an expression pipe such as `currency`, `currency:EUR`, `percent:1`, or `compact:0`.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes.
</ParamField>
</Card>
