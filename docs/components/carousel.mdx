One component, three personalities. Carousel handles interactive slideshows, ambient reels, and continuous marquees — all through configuration, powered by [Embla Carousel](https://www.embla-carousel.com/).

**Carousel** — user navigates with arrows, dots, or swipe. Use `visible` to control how many items are shown at once.

**Reel** — auto-advances on a timer, then holds between ticks. Think airport departure boards.

**Marquee** — continuous smooth scroll that never stops. Think news tickers.

## Carousel

The default mode. Users navigate with arrows (or swipe/drag), with optional dots for direct access:

## Configuration Patterns

### Controls Placement and Dots

Use `controls_position` to choose where arrows render:

- `"outside"` (default): arrows sit outside the viewport and do not cover slide content.
- `"overlay"`: arrows render on top of slides.

Use `show_dots=True` or `False` independently of controls.

```python
from prefab_ui.components import Carousel, Div

# Outside arrows + dots
with Carousel(show_controls=True, controls_position="outside", show_dots=True):
    Div(css_class="bg-blue-500 rounded-lg", style={"height": "160px"})
    Div(css_class="bg-emerald-500 rounded-lg", style={"height": "160px"})
    Div(css_class="bg-violet-500 rounded-lg", style={"height": "160px"})

# Overlay arrows + no dots
with Carousel(show_controls=True, controls_position="overlay", show_dots=False):
    Div(css_class="bg-cyan-500 rounded-lg", style={"height": "160px"})
    Div(css_class="bg-amber-500 rounded-lg", style={"height": "160px"})
    Div(css_class="bg-pink-500 rounded-lg", style={"height": "160px"})
```

### Continuous Marquee Sizing

`continuous=True` controls motion, while `visible` controls sizing:

- `continuous=True` with `visible` omitted uses natural child sizing (`visible=None` behavior).
- `continuous=True, visible=3` creates a 3-up marquee that still scrolls continuously.

```python
from prefab_ui.components import Carousel, Badge, Div

# Natural-size marquee (visible omitted)
with Carousel(continuous=True, speed=2, show_controls=False):
    Badge("Buttons", css_class="mx-2")
    Badge("Cards", css_class="mx-2")
    Badge("Charts", css_class="mx-2")
    Badge("Tables", css_class="mx-2")

# 3-up continuous marquee
with Carousel(continuous=True, visible=3, gap=12, speed=2, show_controls=False):
    Div(css_class="bg-blue-500 rounded-lg", style={"height": "120px"})
    Div(css_class="bg-emerald-500 rounded-lg", style={"height": "120px"})
    Div(css_class="bg-violet-500 rounded-lg", style={"height": "120px"})
    Div(css_class="bg-amber-500 rounded-lg", style={"height": "120px"})
```

### Vertical Notes

- Set `direction="up"` or `direction="down"` for vertical carousels.
- Use `height` (or fixed slide height) so the vertical viewport is deterministic.
- With `controls_position="outside"`, vertical arrows render above/below the viewport, centered to the slide area.

## API Reference

<ParamField body="visible" type="float | None" default="1">
  Slides visible at once. Supports peek values like `1.3`. Set to `None` for
  natural slide sizing (default behavior when `continuous=True` and `visible`
  is omitted).
</ParamField>

<ParamField body="gap" type="int" default="0">
  Pixels between slides.
</ParamField>

<ParamField body="height" type="int | None" default="None">
  Fixed viewport height in pixels. Useful for predictable vertical carousels.
</ParamField>

<ParamField body="direction" type="str" default="left">
  Scroll direction: `"left"`, `"right"`, `"up"`, or `"down"`.
</ParamField>

<ParamField body="loop" type="bool" default="True">
  Loop back to the start after reaching the end.
</ParamField>

<ParamField body="auto_advance" type="int" default="0">
  Milliseconds between auto-advances. `0` = manual navigation only.
</ParamField>

<ParamField body="continuous" type="bool" default="False">
  Smooth continuous scroll (marquee mode) instead of discrete ticks.
</ParamField>

<ParamField body="speed" type="int" default="2">
  Scroll speed for continuous mode (1–10).
</ParamField>

<ParamField body="effect" type="str" default="slide">
  Transition effect: `"slide"` or `"fade"`.
</ParamField>

<ParamField body="dim_inactive" type="bool" default="False">
  Reduce opacity of non-active slides.
</ParamField>

<ParamField body="show_controls" type="bool" default="True">
  Show previous/next navigation arrows.
</ParamField>

<ParamField body="controls_position" type="str" default="outside">
  Arrow placement: `"outside"` (default, off-slide) or `"overlay"` (on-slide).
</ParamField>

<ParamField body="show_dots" type="bool" default="False">
  Show pagination dots below the carousel.
</ParamField>

<ParamField body="pause_on_hover" type="bool" default="True">
  Pause auto-advance or continuous scroll when the mouse hovers.
</ParamField>

<ParamField body="align" type="str" default="start">
  Slide alignment: `"start"`, `"center"`, or `"end"`.
</ParamField>

<ParamField body="slides_to_scroll" type="int" default="1">
  Number of slides to advance per navigation step.
</ParamField>

<ParamField body="drag" type="bool" default="True">
  Allow drag/swipe to navigate.
