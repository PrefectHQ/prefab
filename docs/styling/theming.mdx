title: Theming
description: Apply colors and styles with built-in themes or raw CSS variables.

Prefab uses [shadcn/ui](https://ui.shadcn.com/docs/theming) CSS variables throughout. Pass a `theme` to `PrefabApp` to apply colors across every component in the view:

```python
from prefab_ui.app import PrefabApp
from prefab_ui.themes import Basic, Accent

app = PrefabApp(view=my_view, theme=Basic(accent=Accent.GREEN))
```

## Built-in Themes

### Basic

`Basic` is an accent-driven theme that responds to the user's system color scheme. A single hue controls primary buttons, focus rings, and all five chart colors. Light and dark mode are both handled automatically.

```python
from prefab_ui.themes import Basic, Accent

theme = Basic(accent=Accent.BLUE)
```

Chart colors are distributed evenly around the hue wheel — 72° apart — so visualizations stay legible in both modes without extra configuration.

### Presentation

`Presentation` is an always-dark, data-dense theme with blue-tinted slate surfaces. It suits dashboards and analytics UIs where a dark chrome is the right default.

```python
from prefab_ui.themes import Presentation, Accent

theme = Presentation(accent=Accent.INDIGO)
```

The accent hue drives chart-1, progress and slider fills, badge tints, and table row hover. Charts 2–5 are fixed to emerald, amber, pink, and sky for maximum contrast against the dark background.

## Accent Colors

`Basic` and `Presentation` both accept an `accent` argument: an OKLCH hue in the 0–360 range. The `Accent` enum provides named presets:

| Constant | Hue |
|----------|-----|
| `Accent.BLUE` | 260 |
| `Accent.INDIGO` | 275 |
| `Accent.VIOLET` | 295 |
| `Accent.CYAN` | 215 |
| `Accent.TEAL` | 185 |
| `Accent.GREEN` | 155 |
| `Accent.YELLOW` | 85 |
| `Accent.ORANGE` | 55 |
| `Accent.RED` | 25 |
| `Accent.ROSE` | 350 |
| `Accent.PINK` | 340 |

You can also pass any hue directly: `Basic(accent=200)`.

## Forced Mode

By default, themes respond to the user's system color preference. Set `mode` to pin a specific scheme regardless of OS settings:

```python
Basic(accent=Accent.BLUE, mode="dark")   # always dark
Basic(accent=Accent.BLUE, mode="light")  # always light
```

`mode=None` (the default) follows the system preference. `Presentation` defaults to `mode=None` — if you want to enforce dark mode rather than just defaulting to it, set `mode="dark"` explicitly.

## Custom Themes

`Theme` accepts raw CSS variable declarations. `light_css` is applied under `:root {}`, `dark_css` under `.dark {}`. Omit `dark_css` and the light values apply in both modes:

```python
from prefab_ui.themes import Theme

my_theme = Theme(
    light_css=(
        "--primary: oklch(0.60 0.24 260);"
        " --ring: oklch(0.60 0.24 260);"
    ),
    dark_css=(
        "--primary: oklch(0.70 0.18 260);"
        " --ring: oklch(0.70 0.18 260);"
    ),
)
```

### CSS Overrides

The `css` field accepts any CSS and is injected as-is, without wrapping in a color-scheme selector. Use it for component class overrides, font imports, or rules that apply in both modes:

```python
theme = Theme(
    css="""
    @import url('https://fonts.googleapis.com/css2?family=Inter');
    .cn-card { font-family: 'Inter', sans-serif; }
    """
)
```

The built-in `Presentation` theme uses this for Inter, custom badge styles, and gradient progress fills.

### Variable Reference

Keys are standard [shadcn CSS variable names](https://ui.shadcn.com/docs/theming) without the `--` prefix:

| Variable | Controls |
|----------|----------|
| `primary` / `primary-foreground` | Primary buttons, active states |
| `secondary` / `secondary-foreground` | Secondary buttons |
| `accent` / `accent-foreground` | Highlighted surfaces |
| `background` / `foreground` | Page background and text |
| `card` / `card-foreground` | Card surfaces |
| `muted` / `muted-foreground` | Subdued text and surfaces |
| `destructive` | Delete and error states |
| `border` | Borders and dividers |
| `input` | Input field borders |
| `ring` | Focus rings |
| `chart-1` through `chart-5` | Chart color palette |
| `radius` | Border radius |

Values can be any valid CSS color: `oklch()`, `hsl()`, hex, or named colors.

## shadcn Generators

Any tool that outputs shadcn CSS variables is compatible with Prefab. Copy the blocks directly into `stylesheets` as an inline CSS string:

```python
app = PrefabApp(
    view=my_view,
    stylesheets=["""
        :root { --primary: oklch(0.72 0.19 149); --ring: oklch(0.72 0.19 149); }
        .dark { --primary: oklch(0.77 0.15 163); --ring: oklch(0.77 0.15 163); }
    """],
)
```

<Tip>
Paste only the `:root { ... }` and `.dark { ... }` blocks. Strip out `@import`, `@theme inline`, and `@layer base` — Prefab's renderer already handles the layer structure.
</Tip>
