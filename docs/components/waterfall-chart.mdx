WaterfallChart renders a sequence of values as floating bars, each one starting where the previous bar ended. It's the standard shape for showing how a series of gains and losses roll up into a running total — a profit bridge, a cash flow breakdown, a headcount change over a quarter. Bars are colored automatically: increases, decreases, and totals each get their own color, and dashed "bridge" lines connect one bar to the next.

Like PieChart and RadialChart, WaterfallChart doesn't use `ChartSeries` — instead `data_key` names the value field and `name_key` names the label field, since there's only ever one series of floating bars.

## Totals

Mark a row as a total with `total_key` — a boolean field on each row. Total bars draw from zero instead of stacking on the running total, and they reset the running total for the rows that follow. This is how a waterfall shows a starting balance, a series of changes, and an ending balance in one chart.

## API Reference

<Card icon="code" title="WaterfallChart Parameters">
<ParamField body="data" type="list[dict] | str" required>
  Data as a list of dicts, or a `{{ field }}` interpolation reference.
</ParamField>

<ParamField body="data_key" type="str" required>
  Data key for each row's value. Positive values increase the running total, negative values decrease it.
</ParamField>

<ParamField body="name_key" type="str" required>
  Data key for bar labels.
</ParamField>

<ParamField body="total_key" type="str | None" default="None">
  Data key marking a row as a total (bool). Total bars are drawn from zero instead of stacking on the running total, and reset it for subsequent rows.
</ParamField>

<ParamField body="height" type="int" default="300">
  Chart height in pixels.
</ParamField>

<ParamField body="increase_color" type="str | None" default="None">
  CSS color for increase bars. Defaults to the theme's success color.
</ParamField>

<ParamField body="decrease_color" type="str | None" default="None">
  CSS color for decrease bars. Defaults to the theme's destructive color.
</ParamField>

<ParamField body="total_color" type="str | None" default="None">
  CSS color for total bars. Defaults to the theme's info color.
</ParamField>

<ParamField body="bar_radius" type="int" default="4">
  Corner radius of each bar in pixels.
</ParamField>

<ParamField body="show_connectors" type="bool" default="True">
  Show dashed bridge lines connecting each bar's ending height to the next bar.
</ParamField>

<ParamField body="show_legend" type="bool" default="True">
  Show a legend of the increase/decrease/total categories present in the data.
</ParamField>

<ParamField body="show_tooltip" type="bool" default="True">
  Show tooltips on hover.
</ParamField>

<ParamField body="show_grid" type="bool" default="True">
  Show horizontal grid lines.
</ParamField>

<ParamField body="show_y_axis" type="bool" default="True">
  Show the y-axis with its tick labels.
</ParamField>

<ParamField body="value_format" type="str" default='"auto"'>
  Format value-axis ticks and tooltip values with an expression pipe such as `currency`, `currency:EUR`, `percent:1`, or `compact:0`.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes.
</ParamField>
</Card>
