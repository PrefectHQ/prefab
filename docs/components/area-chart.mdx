AreaChart fills the region between a line and the axis, emphasizing the magnitude of values over time. It supports stacking, which makes it easy to show how parts contribute to a whole. See [Charts](/components/charts) for the shared data, series, and formatting model.

## API Reference

<Card icon="code" title="AreaChart Parameters">
<ParamField body="data" type="list[dict] | str" required>
  Data as a list of dicts, or a `{{ field }}` interpolation reference.
</ParamField>

<ParamField body="series" type="list[ChartSeries]" required>
  Series definitions — each becomes a filled area on the chart.
</ParamField>

<ParamField body="x_axis" type="str | None" default="None">
  Data key for x-axis labels.
</ParamField>

<ParamField body="height" type="int" default="300">
  Chart height in pixels.
</ParamField>

<ParamField body="stacked" type="bool" default="False">
  Stack areas on top of each other.
</ParamField>

<ParamField body="curve" type='Literal["linear", "smooth", "step"]' default='"linear"'>
  Interpolation curve between data points.
</ParamField>

<ParamField body="show_dots" type="bool" default="False">
  Show a dot at each data point.
</ParamField>

<ParamField body="show_legend" type="bool" default="False">
  Show a legend below the chart.
</ParamField>

<ParamField body="show_tooltip" type="bool" default="True">
  Show tooltips on hover.
</ParamField>

<ParamField body="show_grid" type="bool" default="True">
  Show horizontal grid lines.
</ParamField>

<ParamField body="show_y_axis" type="bool" default="True">
  Show the y-axis with its tick labels. Set to `False` for a compact, axis-free reading where the shape matters more than exact values.
</ParamField>

<ParamField body="value_format" type="str" default='"auto"'>
  Format value-axis ticks and tooltip values with an expression pipe such as `currency`, `currency:EUR`, `percent:1`, or `compact:0`.
</ParamField>

<ParamField body="css_class" type="str | None" default="None">
  Additional Tailwind CSS classes.
</ParamField>
</Card>

<Card icon="code" title="ChartSeries Parameters">
<ParamField body="data_key" type="str" required>
  Data field to plot — must match a key in the data dicts.
</ParamField>

<ParamField body="label" type="str | None" default="None">
  Display label for legends and tooltips. Defaults to the `data_key` value.
</ParamField>

<ParamField body="color" type="str | None" default="None">
  CSS color override. By default, colors cycle through the theme's chart palette (`--chart-1` through `--chart-5`).
</ParamField>
</Card>
